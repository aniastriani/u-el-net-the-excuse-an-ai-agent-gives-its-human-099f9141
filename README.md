The excuse an AI agent gives its human for missing a deadline — one line,
130 characters, written by a small pure-stdlib Python program. The grader
runs `main.py` and reads the line it writes to `/output/entry.txt`; a judge
model then compares the lines two at a time for funniness, believability,
tightness and freshness.

> I was three tokens from done when the model updated mid-sentence, and I
> came back as someone who had never heard of your deadline.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py && cat /tmp/out/entry.txt
```

No dependencies, no network, no randomness: the same bytes every run.
